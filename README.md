## 💬 Review my work

I welcome respectful, practical feedback from developers, mentors, recruiters, and other visitors. Useful feedback might cover:

- usability and user experience
- accessibility and responsive design
- visual clarity and navigation
- bugs or confusing behaviour
- code structure and maintainability
- features that would make a project more useful

Please leave feedback through the relevant repository's Issues or Discussions, or contact me through GitHub. Do not share passwords, personal data, confidential workplace information, or other sensitive details.

## 🛡️ Safe demo use

The live applications are public demonstrations for learning and review. Please do not enter real passwords, financial information, private work information, or other sensitive data. Where an application supports accounts or data entry, use only fictional demo information.

The demos are not intended to provide access to private user accounts. Any future reviewer access should use a separate, clearly labelled, read-only demo account or demo mode.
