## ⚙️ Practical workplace automation

I also build automation tools that are used in my workplace. One example is a Tampermonkey userscript that helps automate a repetitive EDWatch publishing workflow, including:

- Detecting the active station
- Remembering station-specific working hours and journalist schedules
- Applying filters and skipping unsuitable stories
- Assigning journalists by story hour
- Setting category, company, and neutral tonality
- Publishing and moving continuously to the next eligible story
- Handling page transitions and station changes safely

This tool is used by a team of approximately 24 people. The workplace system is only available on the company network, so it cannot be demonstrated publicly from my computer.
